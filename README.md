# X Follower Tracker v1.2

**ボタン1つで更新**できる X（Twitter）フォロワー管理 Chrome拡張機能です。

- 公式APIキー不要
- パスワード入力不要（ChromeでXにログインしていればOK）
- データはすべてブラウザ内に保存

## 使い方

### 普段の確認
拡張機能アイコンを押すだけで、新規・解除の人数と一覧が表示されます。

### 更新（ページを開かなくてOK）
1. Chromeで X にログインしている状態にする
2. 拡張機能を開き **「データを更新する」** を押す
3. 自動でフォロワー一覧を取得し、前回と比較して差分を記録

フォロワーページを開く必要はありません。

### うまくいかないとき
- Xの内部仕様変更で自動取得が失敗することがあります
- その場合は `https://x.com/自分のID/followers` を開き、「表示分だけ」または「ページ自動取得」を使ってください

## インストール

1. ZIPを解凍
2. `chrome://extensions` を開く
3. デベロッパーモードをON
4. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択

## 注意

- 非公式のセッション利用です。過度な連続更新は避けてください
- Xの仕様変更で動かなくなる可能性があります
