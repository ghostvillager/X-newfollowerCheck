# X Follower Tracker (Large Scale) v2.0

数万人規模のフォロワーを **内部REST v1.1 API** で取得・差分管理するChrome拡張機能です。

- DOMスクロール不要
- 公式APIキー不要（ログイン中のセッションを使用）
- 1ページ最大200人 × ページネーション
- 途中停止・再開対応（基本）
- 新規 / 解除を自動検出

## 使い方

1. Chromeで **x.com にログイン**した状態にする
2. このフォルダを `chrome://extensions` で「パッケージ化されていない拡張機能を読み込む」
3. 拡張機能を開いて **「フルスキャン開始」** を押す
4. 数万人の場合は15〜40分程度かかります（進捗が表示されます）

## 注意

- 非公式のセッション利用です。過度な連続実行は避けてください
- Xの仕様変更で動かなくなる可能性があります
- 自己責任でご利用ください
- 初回はフルスキャン、以降は差分管理が主になります

## 技術

- エンドポイント: `https://x.com/i/api/1.1/followers/list.json`
- 認証: cookie (`ct0`, `auth_token`) + 公開Bearerトークン
- 保存先: `chrome.storage.local`
